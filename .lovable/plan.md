# Software Vala product-card refinement

## Goal
Polish the existing homepage product cards to match the supplied reference while preserving every product, category, section, state, action, URL, and business behavior.

## Changes
- Keep the current dark Software Vala visual family, but improve card surface depth, border consistency, and internal vertical balance.
- Establish a clear hierarchy for title, category, description, feature/technology chips, current price, previous price, and metadata.
- Give Live Demo, Buy Now, Notify Me, and disabled Coming Soon controls a restrained premium 3D treatment with hover, pressed, focus, and disabled states.
- Rework the clients/rating/delivery area into a compact, aligned three-column metric strip anchored at the card bottom.
- Reduce excessive carousel-row gaps and balance horizontal card spacing across desktop, laptop, tablet, and mobile widths.
- Preserve all existing card interactions, tab behavior, favorites, links, notifications, data, and carousel behavior.

## Validation
- Inspect active and coming-soon cards at desktop, tablet, and mobile widths.
- Verify buttons, feature/technology tabs, favorites, and links still respond correctly.
- Check card heights, metric alignment, row density, clipping, and horizontal scrolling.
- Run the available lint/type checks and rely on the automatic project build validation.
